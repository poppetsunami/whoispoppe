Figma Make Prompt

Create a modern portfolio homepage for a senior product designer.

The portfolio should function as an expanded resume, allowing visitors to quickly scan experience and selectively expand sections to see project details.

The design style should be clean, modern, and slightly funky, using strong typography, minimal color, and subtle visual accents.

Use Poppins as the primary typeface.
