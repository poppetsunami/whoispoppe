Update Experience Accordions to Support Expanded Role Content

Update the existing Experience accordion cards on the portfolio homepage to support deeper professional storytelling while preserving the current visual design system.

Do not redesign the page layout. Instead, enhance the accordion interaction and internal content structure.

Maintain:

• current spacing
• card styling
• rounded corners
• green accent color
• Poppins typography
• overall layout hierarchy

The accordion cards should remain visually minimal when collapsed but reveal detailed structured content when expanded.

Accordion Behavior

Each experience card should support two states:

Collapsed State

Displays:

Role Title
Company + Dates
1-line description of the work

Example:

Principal UX Designer
KAMP Technologies | 2025–Present

Designing connected platforms integrating machine telemetry, fleet monitoring, and operational analytics.

Include a subtle expand arrow icon on the right.

Expanded State

When expanded, the card reveals three structured sections:

Overview
Key Contributions
How I Approach the Work

These sections should be visually separated using subheadings and spacing, not heavy borders.

Expanded Content Layout

Inside the expanded accordion, structure content like this:

Overview

Paragraph text explaining the product environment and the design challenge.

Spacing:
16px margin below heading
24px margin below section

Key Contributions

Display contributions as a bullet list.

Bullets should be visually simple and aligned with the card grid.

Example formatting:

• Defined the foundational interaction models for translating machine telemetry into actionable insights
• Designed dashboards and reporting workflows supporting fleet and equipment management
• Established core design patterns and UI architecture for the platform
• Worked closely with engineering to translate data structures into usable product features
• Facilitated product discussions around prioritization, user needs, and platform direction
• Introduced early design system structure to support product scalability

Spacing:

8–12px between bullets

How I Approach the Work

This section contains 2–3 paragraphs describing design thinking and leadership approach.

Text should remain highly readable:

• max line width ~70 characters
• increased line height (1.5–1.6)
• generous vertical spacing

This section communicates design philosophy and leadership thinking, so ensure it reads comfortably.

Optional Case Study Link

At the bottom of the expanded accordion, include a subtle action:

View Case Study →
or
Request Case Study Access

Style:

• small secondary button
• outline or ghost style
• green accent hover

This allows linking to password-protected case studies later.

Interaction Behavior

Accordion animation:

• smooth expand/collapse
• 200–250ms transition
• content pushes page downward rather than overlaying

Ensure only one accordion expands at a time to maintain readability.

Typography

Use the site's existing Poppins typography scale.

Section headings inside accordion:

SemiBold
16–18px

Body text:

Regular
14–16px

Bullets:

Same body size but slightly tighter line height.

Accessibility Considerations

Ensure accordion supports:

• keyboard navigation
• clear focus states
• semantic grouping of headings
